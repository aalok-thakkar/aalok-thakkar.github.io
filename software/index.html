Aalok Thakkar: Software

Research software

DiagonaLean

A Lean 4 library of machine-checked undecidability results, built on Mathlib and Cslib. Every result is a chain of reductions from the halting problem for Turing machines, and each reduction comes with a correctness proof. The library covers the modified and classical Post Correspondence Problems, string rewriting, membership for unrestricted grammars, ambiguity and intersection of context-free grammars, matrix mortality, SKI and β-convertibility, and Rice's theorem. It also formalises the undecidability of Kleene algebra with commutativity conditions (Azevedo de Amorim, Zhang and Gaboardi), and finds and repairs an error in that paper's Theorem 6. Undecidability is stated in two ways: as a reduction that Lean must compile, and as the absence of a Turing machine that decides the problem under a given encoding. With TVH Prathamesh, Akhilesh Balaji and others.

minimal-trust-tool

Given a security protocol, a goal and a finite set of candidate assumptions, computes every minimal set of assumptions under which the goal holds, together with the minimal attacks. It runs a counterexample-guided loop over a protocol verifier, with a bounded Dolev-Yao analyser and CPSA as oracles. Tool for “The Trust a Protocol Needs” (ICISS 2026), with Bhumika Mittal.

EGS

Example-guided synthesis of relational queries from input-output examples. The artifact packages EGS with ILASP, ProSynth and Scythe, the benchmarks, and scripts to reproduce the experiments of the PLDI 2021 paper.

echogae

A reproduction of Alatawi, Sheth and Liu (2023), “Quantifying the Echo Chamber Effect”, submitted to ReScience C. The reproduction matches the paper's headline score and documents that the paper's Equation 4 and the released code compute different quantities under the same name.

Libraries

ocaml-highs

OCaml bindings for the HiGHS solver for linear, mixed-integer and quadratic programming. A problem is an immutable OCaml record, and solving it returns a new solution record.

ocaml-hexaly

OCaml bindings for the Hexaly optimizer, including its interval, list and set decision variables for scheduling and routing. Install with opam install hexaly (see the opam package and the API documentation). Hexaly is commercial, so each user needs their own installation and licence; there is a free academic licence.

kolam-tikz

A TikZ package for drawing pulli kolams. Place the dots at integer coordinates, name the gates between them, and the package draws the strands.

Margazhi

A free typeface drawn as pulli kolam, in Regular and Bold. Uppercase letters are filled, lowercase letters are outlines, and the number row holds twelve geometric designs. Every glyph is generated from a rule and drawn with kolam-tikz. Comes as OTF, web fonts and a LaTeX package, under the SIL Open Font License. Source and download.
